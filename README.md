# 种毛衣

依据三份附件制作的网站与微信小游戏可玩预览版。两端共享纯 JavaScript 游戏逻辑及 JSON 配置；网站为响应式 HTML/CSS，微信端采用附件允许的原生 Canvas 路线，无需安装 Cocos Creator。

## 运行网站

在此目录运行 `npm start`，打开 http://127.0.0.1:4173 。Node.js 18 或以上；无需安装第三方依赖。网站源文件和静态发布内容在 `dist/`。

## 打开微信小游戏

微信开发者工具中选择小游戏，导入 `minigame/`。工程使用 `touristappid` 作为开发占位；正式预览、上传和提审前，在 `minigame/project.config.json` 配置自己的小游戏 AppID。此项目是微信小游戏，不是普通 WXML 小程序，也不是网页套壳。

微信端包含触控排序、小院种植、纺线、编织、图鉴、签到、每日挑战、设置与本地存档。未在真实微信客户端验证；需在开发者工具、iOS 和 Android 真机完成测试。网页和微信端存档分别保存在各自设备，不自动互通。

## 当前实现

- 300 个确定性生成且经 BFS 求解器验证的关卡；布局互不重复。支持同色段移动、部分移动、撤回、提示、加柱、重开、胜利结算与关卡存档。
- 第 3 关后种植、5 关后纺线、8 关后编织、12 关后签到和每日挑战。第 15 关出现打结，25 关出现小猫；小猫可点三次移除。
- 9 块地、8 种棉花、3 台可解锁纺车、5 个图样；棉花和纺车按时间戳结算，支持离线 12 小时封顶、防时间回拨。
- 7 日签到，断签不清零；每日挑战按本机日期生成相同布局、每天发奖一次。
- 本地存档及备份回退。网页端另有存档导入导出、作品分享图片、程序合成的轻音、色弱辅助图案。
- 原创 SVG 插画与 Canvas 图形、响应式布局，无远程字体或图片依赖。

## 配置与验证

`game-config.json` 是数值、品种、配方、图样、签到奖励的可编辑源文件。`npm run build` 更新网站运行配置并同步共享逻辑至微信目录；`npm run gen:levels -- --regenerate` 可重新生成关卡（或直接 `node tools/build.cjs --regenerate`）。关卡数值初值来自附件，不代表留存或收入已经验证。

`npm test` 运行规则与生产链测试；`npm run validate:config` 验证交叉引用与关卡数量不变量；构建会检查微信目录小于附件提出的 3.8MB 预算。无第三方运行依赖。

## 发布前仍需完成

当前交付为可玩预览版，不能等同于附件全部 M1–M7 的商业发行验收。尚未接入真实广告、云存档、微信后台埋点、实名/防沉迷、发行主体隐私文本或正式适龄标识。无广告时不发放模拟视频奖励；加柱使用道具或 50 金币。插屏未启用。

P2 的邻居订单和节日限定尚未实现；图样目前为基础与田园系列，未显示虚假可领取活动。新手引导为说明式引导，尚未实现附件逐步遮罩引导。微信端图鉴为 Canvas 简化展示，网页端具有完整图样插画和编织网格。当前不提供背景音乐和云端分析。

发行者需配置 AppID、核实平台最新资质要求、完成名称及美术权利核查、填写运营方及联系方式、完善正式协议、完成微信真机测试与平台审核。没有凭证时不代填账号信息，也不声称已经发布到微信。

网站托管身份保存在 `.openai/hosting.json`；保持其中项目 ID 不变，复用该项目发布后续版本。

## 工程结构

`dist/core.js`：规则、求解器、可复现关卡生成与经济生产链；`dist/app.js`：网页交互；`dist/style.css`：桌面及移动布局；`dist/assets/`：原创图形；`minigame/game.js`：微信 Canvas 入口；`tests/`：自动化验证；`tools/`：构建、配置检查和本地服务；`docs/`：验收记录。

微信开发接口参考：[Canvas](https://developers.weixin.qq.com/minigame/dev/api/render/canvas/wx.createCanvas.html)、[触摸事件](https://developers.weixin.qq.com/minigame/dev/api/device/touch-event/wx.onTouchEnd.html)。官方文档在当前检索环境未能打开，实际兼容性需通过微信开发者工具验证。
